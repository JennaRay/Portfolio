Ride Share App Design (2025)

For this project I collaborated with a multidisciplinary team to create a 200 + page design document for a ride sharing app. The design document focused on the backend design of the application, including the database schema, server architecture, and API design. My personal contribution to the project included designing sub components of the app, such as the reviews page and the payment history page, and reviewing and refining design documentation contributions for 20+ individuals, identifying critical issues and ensuring compliance with project requirements, which contributed to improved project timelines.
